# Python Password Manager Core Concepts

This example demonstrates core concepts for building a password manager, focusing on security principles using Python's standard library. It shows how to generate strong, random passwords and how to securely derive an encryption key from a master password using PBKDF2. The example simulates an in-memory password vault, explicitly noting where actual encryption and decryption would occur in a real-world application, which would typically require external cryptographic libraries.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
